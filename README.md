# Tariq-Zeyad-OOP-Assignment-1

A collection of practical C# implementations focused on **Object-Oriented Programming, Design Patterns, and Algorithmic Problem Solving**.

## ✦ Highlights

### 01 · Procedural to OOP
Transformed a procedural order management system into a structured, maintainable OOP solution using encapsulation and clear class responsibilities.

### 02 · Hotel Reservation System
Designed a complete reservation domain with guests, rooms, reservations, validation, availability rules, and controlled state transitions.

### 03 · Builder Pattern
Implemented a fluent and composable Builder Pattern with reusable address construction, validation, and separation of responsibilities.

### 04 · LeetCode 1679
Implemented an efficient **Two Pointers** solution for the K-Sum Pairs problem using sorting and controlled pointer movement.
